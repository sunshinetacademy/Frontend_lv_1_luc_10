CSS Grid — Layout ثنائي الأبعاد

أقوى نظام Layout في CSS الحديث. هنتعلم إزاي نبني Layoutات معقدة بصفوف وأعمدة، ونتحكم في كل خلية بشكل مستقل.

🔄
مراجعة سريعة

📚 من المحاضرة اللي فاتت

  • Flexbox = نظام Layout أحادي البعد
  • display: flex + justify-content + align-items
  • flex-direction, flex-wrap, gap
  • flex-grow, flex-shrink, flex-basis
  • Navbar و Cards Layout بـ Flexbox

🎯 هدف النهاردة

النهاردة هننتقل لـ CSS Grid — نظام Layout ثنائي الأبعاد (صفوف + أعمدة مع بعض). Grid بيحل مشاكل Flexbox في الـ Layoutات المعقدة. تخيل إن Flexbox زي القطار (سطر واحد)، و Grid زي رقعة الشطرنج (صفوف وأعمدة).

ما هو CSS Grid؟

📖 التعريف

CSS Grid (Grid Layout) هو نظام Layout ثنائي الأبعاد في CSS. بيخلينا نبني Layoutات بـ صفوف وأعمدة في نفس الوقت، ونتحكم في كل خلية بشكل مستقل.

Grid بيحل مشاكل Flexbox في الـ Layoutات المعقدة زي: صفحات كاملة، Galleries، Dashboards.

💡 تشبيه من الحياة

قارن بين Flexbox و Grid:

  • Flexbox = القطار (عربات في سطر واحد، اتجاه واحد)
  • Grid = رقعة الشطرنج (صفوف + أعمدة، اتجاهين)
  • Flexbox = 1D (خط أفقي أو رأسي)
  • Grid = 2D (شبكة كاملة)
🚂

Flexbox

1D Layout — اتجاه واحد

• صف أو عمود

• مرن في التوزيع

• أفضل للمكونات الصغيرة

استخدمه في: Navbar, Cards row, Centering
🔲

CSS Grid

2D Layout — اتجاهين

• صفوف + أعمدة

• تحكم دقيق في كل خلية

• أفضل للصفحات الكاملة

استخدمه في: Page Layout, Gallery, Dashboard

Grid Container vs Grid Items

📖 المفهوم الأساسي

زي Flexbox بالظبط، Grid بيعتمد على علاقة بين عنصرين:

1. Grid Container (الأب): العنصر اللي عليه display: grid

2. Grid Items (الأبناء): العناصر المباشرة جوه الـ Container

CSS — تفعيل Grid 
/* الأب = Grid Container */
.container {
    display: grid;
}

/* الأبناء = Grid Items (تلقائياً) */

Columns & Rows — الأعمدة والصفوف

📖 تحديد الأعمدة والصفوف

أهم property في Grid هو grid-template-columns و grid-template-rows. بيحددوا عدد وحجم الأعمدة والصفوف.

CSS — Columns & Rows 
.container {
    display: grid;
    grid-template-columns: 200px 200px 200px; /* 3 أعمدة */
    grid-template-rows: 100px 100px; /* صفين */
}

/* باستخدام repeat() */
.container {
    grid-template-columns: repeat(3, 200px); /* نفس النتيجة */
}

fr Unit — وحدة الكسر (Fraction)

📖 ما هي fr؟

fr (fraction) هي وحدة خاصة بـ Grid. بتوزع المساحة الفاضية على الأعمدة بنسب.

• 1fr = جزء واحد من المساحة الفاضية

• 2fr = جزئين (ضعف 1fr)

• 1fr 1fr 1fr = 3 أعمدة متساوية

Grid Lines — خطوط الشبكة

📖 التحكم في موقع العنصر

Grid بيخلق خطوط وهمية (Grid Lines) بين الخلايا. نقدر نحدد موقع العنصر باستخدام الخطوط دي.

• grid-column = تحديد بداية ونهاية العمود

• grid-row = تحديد بداية ونهاية الصف

🔍 فهم الترقيم

الخطوط بتترقم من 1. لو عندك 3 أعمدة، هيبقى في 4 خطوط عمودية (1, 2, 3, 4).

1     2     3     4
|   |   |   |
| Col1 | Col2 | Col3 |
|   |   |   |

CSS — Grid Lines 
.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    grid-template-rows: 100px 100px;
}

/* عنصر يمتد من العمود 1 للعمود 3 */
.item {
    grid-column: 1 / 3; /* من خط 1 لخط 3 */
}

/* عنصر يمتد من الصف 1 للصف 3 */
.item {
    grid-row: 1 / 3;
}

/* Shorthand */
.item {
    : 1 / 3;
    : 2 / 4;
}

🗺️
Grid Template Areas — تسمية المناطق

📖 تخطيط بصري

grid-template-areas بيخليك ترسم الـ Layout بشكل بصري باستخدام أسماء. ده أسهل بكتير من حساب الخطوط!

CSS — Grid Areas 
.container {
    display: grid;
    grid-template-areas:
        "header header header"
        "nav    main   aside"
        "footer footer footer";
    grid-template-columns: 1fr 3fr 1fr;
    grid-template-rows: 60px 1fr 60px;
}

.header { grid-area: header; }
.nav { grid-area: nav; }
.main { grid-area: main; }
.aside { grid-area: aside; }
.footer { grid-area: footer; }

💡 ميزة Areas

• بصري: بتشوف الـ Layout قبل ما تكتبه

• سهل الصيانة: غير الترتيب بسطر واحد

• Responsive: غير الـ areas في media query

CSS — Responsive Areas 
/* Desktop */
.container {
    grid-template-areas:
        "header header header"
        "nav    main   aside"
        "footer footer footer";
}

/* Mobile */
@media (max-width: 768px) {
    .container {
        grid-template-areas:
            "header"
            "nav"
            "main"
            "aside"
            "footer";
        grid-template-columns: 1fr;
    }
}

Auto-fit & minmax — Grid متجاوب

📖 Grid متجاوب تلقائياً

باستخدام auto-fit أو auto-fill مع minmax()، نقدر نعمل Grid يتجاوب تلقائياً بدون media queries!

auto-fit
تلقائي

بيخلق أكبر عدد ممكن من الأعمدة اللي بتتسع. الأعمدة الفاضية بتنضغط.

auto-fill
تلقائي مع ملء

زي auto-fit لكن بيحافظ على الأعمدة الفاضية.

minmax(min, max)
نطاق مرن

بيحدد أقل وأكبر حجم للعمود. مثلاً: minmax(200px, 1fr)

CSS — Responsive Grid 
/* Cards تتجاوب تلقائياً */
.cards-container {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
    gap: 2rem;
}

/* يعني: */
/* - كل card على الأقل 250px */
/* - لو في مساحة، الكاردز بتكبر */
/* - عدد الأعمدة بيتغير حسب عرض الشاشة */

Alignment في Grid

📖 محاذاة العناصر

Grid بيعرض نفس خصائص المحاذاة اللي في Flexbox:

justify-items
محاذاة أفقية

محاذاة العناصر جوه خلاياها أفقياً (start, center, end, stretch)

align-items
محاذاة رأسية

محاذاة العناصر جوه خلاياها رأسياً (start, center, end, stretch)

place-items
Shorthand

justify + align في خاصية واحدة

justify-content
محاذاة الشبكة

محاذاة الشبكة كلها جوه الـ Container

CSS — Alignment 
/* توسيط العناصر جوه خلاياها */
.container {
    place-items: center;
}

/* توسيط الشبكة نفسها */
.container {
    justify-content: center;
    align-content: center;
    min-height: 100vh;
}

✨ أسهل طريقة للتوسيط الكامل

عشان توسط عنصر في الصفحة:

body {
  display: grid;
  place-items: center;
  min-height: 100vh;
}

🤔
Grid vs Flexbox — متى نستخدم كل واحد؟

📖 القاعدة الذهبية

Flexbox = مكونات صغيرة (1D) — Navbar, Cards row, Centering

Grid = Layoutات كبيرة (2D) — Page layout, Gallery, Dashboard

🚂

استخدم Flexbox لما:

• عايز ترتيب عناصر في سطر واحد

• عايز توزيع مرن للمساحة

• المحتوى هو اللي بيحدد الحجم

• Components صغيرة (زر، card، nav item)

أمثلة: Navbar, Button group, Cards row, Centering
🔲

استخدم Grid لما:

• عايز صفوف وأعمدة مع بعض

• عايز تحكم دقيق في كل خلية

• الـ Layout هو اللي بيحدد الحجم

• Page layouts كبيرة ومعقدة

أمثلة: Page layout, Photo gallery, Dashboard, Forms

💡 مش لازم تختار!

في الواقع، المحترفين بيستخدموا الاتنين مع بعض:

• Grid للـ Layout الرئيسي للصفحة

• Flexbox للمكونات جوه كل منطقة

• Grid + Flexbox = أقوى Combo في CSS

ملخص Grid Properties

📊 Container Properties

Property الوظيفة مثال
display تفعيل Grid grid, inline-grid
grid-template-columns تعريف الأعمدة 1fr 1fr 1fr, repeat(3, 1fr)
grid-template-rows تعريف الصفوف 100px 1fr 100px
grid-template-areas تسمية المناطق "header header" "main aside"
gap المسافة بين الخلايا 20px, 1rem 2rem
justify-items محاذاة أفقية للعناصر start, center, end, stretch
align-items محاذاة رأسية للعناصر start, center, end, stretch
place-items Shorthand center
justify-content محاذاة الشبكة center, space-between
align-content محاذاة الشبكة رأسياً center, space-between

📊 Item Properties

Property الوظيفة مثال
grid-column موقع العمود 1 / 3, span 2
grid-row موقع الصف 1 / 3, span 2
grid-area اسم المنطقة header, main, nav
justify-self محاذاة فردية أفقية start, center, end
align-self محاذاة فردية رأسية start, center, end

Debugging — اكتشف الأخطاء

🔍 نشاط: اكتشف الأخطاء في CSS ده

الكود ده فيه 5 أخطاء شائعة في Grid.

CSS — كود فيه أخطاء ❌ 
.container {
    display: gridbox;
    grid-template-columns: 3fr;
    gap: 20;
}

.item {
    grid-column: 1 3;
    grid-area: 1 / 2;

❌ الأخطاء
1. display: gridbox ❌
2. 3fr ❌ (لازم repeat أو قيم)
3. gap: 20 (بدون وحدة) ❌

5. grid-area: 1/2 ❌ (لازم اسم)

📌 ملخص المحاضرة

  • CSS Grid = نظام Layout ثنائي الأبعاد (2D)
  • display: grid يحوّل العنصر لـ Grid Container
  • grid-template-columns + grid-template-rows لتحديد الأعمدة والصفوف
  • fr (fraction) = وحدة مرنة بتوزع المساحة الفاضية
  • repeat(3, 1fr) = 3 أعمدة متساوية
  • gap = المسافة بين الخلايا (أفضل من margin)
  • grid-column + grid-row = التحكم في موقع العنصر
  • span 2 = يمتد على عمودين أو صفين
  • grid-template-areas = تخطيط بصري باستخدام أسماء
  • auto-fit + minmax = Grid متجاوب تلقائياً بدون media queries
  • place-items: center = أسهل طريقة للتوسيط
  • Flexbox = 1D (مكونات)، Grid = 2D (Layoutات)
  • المحترفون بيستخدموا الاتنين مع بعض

أسئلة اختيار من متعدد

10 أسئلة لاختبار فهمك لمحتوى المحاضرة

سؤال 1

ما هو value اللي بيحوّل العنصر لـ Grid Container؟

  • أ display: gridbox
  • ب display: grid
  • ج display: table
  • د grid: container
سؤال 2

ما هي وحدة fr في Grid؟

  • أ fixed ratio
  • ب fraction — جزء من المساحة الفاضية
  • ج frame rate
  • د full row
سؤال 3

إزاي تعمل 3 أعمدة متساوية بـ Grid؟

  • أ grid-template-columns: 3fr;
  • ب grid-template-columns: 1fr 1fr 1fr;
  • ج grid-columns: 3;
  • د columns: 3;
سؤال 4

ما وظيفة repeat(3, 1fr)؟

  • أ يكرر العنصر 3 مرات
  • ب يخلق 3 أعمدة متساوية
  • ج يخلق 3 صفوف
  • د يكرر الـ gap 3 مرات
سؤال 5

ما وظيفة grid-template-areas؟

  • أ يحدد ألوان المناطق
  • ب يسمي المناطق ويرتبها بشكل بصري
  • ج يحدد حجم المناطق
  • د يخفي المناطق
سؤال 6

إزاي تخلي عنصر يمتد على عمودين؟

  • أ grid-column: 2;
  • ب grid-column: span 2;
  • ج column-span: 2;
  • د grid-width: 2;
سؤال 7

ما وظيفة auto-fit في Grid؟

  • أ يملأ الفراغات
  • ب يخلق أكبر عدد ممكن من الأعمدة اللي بتتسع
  • ج يغير حجم الخط تلقائياً
  • د يخفي الأعمدة الفاضية
سؤال 8

ما وظيفة minmax(200px, 1fr)؟

  • أ يحدد أقل حجم 200px وأكبر حجم 1fr
  • ب يحدد حجم ثابت 200px
  • ج يحدد حجم 1fr فقط
  • د يخفي العناصر الصغيرة
سؤال 9

ما هو الفرق الرئيسي بين Flexbox و Grid؟

  • أ مفيش فرق
  • ب Flexbox = 1D (سطر أو عمود)، Grid = 2D (صفوف وأعمدة)
  • ج Flexbox أحدث من Grid
  • د Grid أسهل من Flexbox
سؤال 10

إزاي توسط عنصر في الصفحة بـ Grid؟

  • أ margin: auto;
  • ب display: grid + place-items: center + min-height: 100vh;
  • ج text-align: center;

📌 الواجب الأول: Grid Basics

ابني 3 containers مختلفة:

  • Container 1: 3 أعمدة ثابتة (200px) — 6 items
  • Container 2: 4 أعمدة بـ fr — 8 items
  • Container 3: أعمدة مختلفة الأحجام (100px, 1fr, 2fr, 1fr) — 8 items
  • كل container بلون مختلف للخلفية
  • اكتب تحت كل container شرح للسلوك

📌 الواجب الثاني: Grid Lines

ابني Grid فيه 3 أعمدة و 3 صفوف:

  • عنصر يمتد على عمودين (grid-column: span 2)
  • عنصر يمتد على صفين (grid-row: span 2)
  • عنصر في الزاوية (grid-column: 1 / 2; grid-row: 1 / 2)
  • عنصر في النص يمتد على عمودين وصفين
  • استخدم ألوان مختلفة لكل عنصر
